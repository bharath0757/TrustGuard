# Development Guide

## How to Start Work

1. Clone the repository: `git clone https://github.com/bharath0757/TrustGuard.git`
2. Configure Git identity if required.
3. Switch to develop: `git checkout develop`
4. Create their feature branch: `git checkout -b feature/<module_name>`
5. Work on their assigned module.
6. Commit changes: `git commit -m "Your descriptive message"`
7. Push the branch: `git push origin feature/<module_name>`
8. Open a pull request against `develop`.
9. Keep their branch synchronized with develop: `git pull origin develop`
